# antislop audit 002, 2026-09-25

Scope: surfaces shipped since audit 001 (`b797fa5`) without an audit, at `17ac018`: the report flow (#168),
the map's new detail views (#170 to #174: citizen reports, earthquakes, airport weather, official detail),
and the admin additions (report moderation, the zone push table, the push test of #177). Forecast and
history had their own gate in #166.
Method: code inspection; a sweep proposed candidates, every item below re-read at its line by the lead.
Priority follows the rule tier: Hard Gate HIGH, Purpose-Gate MEDIUM, Quality Locks LOW.

## HIGH

1. R-27 admin: `PushDeviceTest.tsx:12-15` never reads `arrival.isError`, and the one-minute expiry is computed
   only inside a successful poll. If the poll fails, the button says "waiting" forever.
2. R-27 admin: `PushDeviceTest.tsx:50` shows the server's English error text (`push-test.server.ts`, e.g.
   "Please wait one minute") in every locale.
3. R-27 admin: `ReportModeration.tsx:240` shows the raw PostgREST error to moderators, untranslated.
4. R-02 map: em dash in `civilMap.offline` (map list offline notice) and `official.disclaimer` (official
   incident detail), in all four locales.
5. R-02 + R-27 map: `CivilSituation.tsx:406,412` renders a lone "—" for an unknown fire area and peak FRP,
   with no reason (the pattern audit 001 item 10 removed from admin).
6. R-03 map: `HazardReportDetail.tsx:98` the "sign in to confirm" call to action is an inline text link with
   no 44 px target.
7. R-03 admin: `BroadcastConsole.tsx:202` the authority-warning form's selects are 36 px with no coarse-pointer
   override (`ui/button` has one since audit 001; this raw `select` class does not).

## MEDIUM

8. R-27 report: `report.tsx:475` a failure loading "My reports" says only "Something went wrong", with no
   retry.
9. R-06 map: `CivilSituation.tsx:156` the situation card's source label is 11 px uppercase wide-tracked with
   no written reason (audit 001 item 11 removed these elsewhere).
10. Four-locale rule (project): `BroadcastConsole.tsx:268-269` severity options "Severe" and "Extreme" are
    hard-coded English in every locale.

## LOW

11. R-27 report: `report.tsx:66` never reads `units.isError`; if places fail to load, the commune line
    silently disappears from the report form.
12. R-26 map: `HazardReportDetail.tsx:97` signing in to confirm a report returns to the map root
    (`returnTo: "/"`), so the report being confirmed is lost.
13. R-38 report: `LevelCard.tsx:85` "People alerted" counts people whose in-app alert included the report,
    not pushes delivered; the label does not say which.

Rejected: the sweep also flagged `admin/kit/QueryState.tsx:38` for printing the backend message. It sits under
a translated heading with a retry button, so cause and next action are given; the raw detail is for
operators. Not a defect.

Clean: Arabic strings (no leftover English beyond the proper noun "Info Trafic Algérie"), muted-text contrast
on raised surfaces (5.24:1 light, 6.29:1 dark), no endless motion or decorative dots, the report form's tiles
and buttons reach 44 px, quake and airport details use translated strings only, LevelCard points match the
SQL formula and its explanation, report errors are translation keys.
