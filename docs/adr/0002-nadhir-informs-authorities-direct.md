# Nadhir informs; only authorities direct

Nadhir never issues a directive (evacuate, shelter here, take this road) in its own
voice. Its voice is limited to Information — observations with timestamp and source, and
model output labelled as such. Directive language on screen is either a relayed, verified
authority Instruction or pre-approved Standing Guidance, which may be imperative but
never names a route, destination or timing. Chosen over the stronger "app commands you"
UX because Nadhir's detection is hours-latency satellite data with no spread model: a
confident wrong "LEAVE NOW via N12" from an unaccountable open-source project can kill,
and the informing stance is what makes Protection Civile a possible partner instead of an
adversary. See CONTEXT.md: Information / Instruction / Standing Guidance.

## Consequences

- The flagship "safest route + ETA" screen is gated on an institutional relationship and
  a validated spread model, not on engineering.
- "Safe" is banned as a status label; Check-In records that a button was tapped, nothing
  more.
- SOS shows no "request received" acknowledgment until a staffed receiver exists.
